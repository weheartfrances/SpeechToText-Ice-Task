# Speech-to-Text and Text-to-Speech Chatbot

Project Description
This project is a Java chatbot that uses FreeTTS to convert text into speech. I added a text-to-speech feature, a basic chatbot that responds to messages like "hello" and "bye", and an option to display the available voices. The chatbot can also speak its responses aloud.

Features Added
- Text-to-speech using FreeTTS.
- A basic chatbot with predefined responses.
- Spoken chatbot responses.
- An option to display available voices.
- A console menu for navigating the different options.
- Basic input validation for incorrect menu entries.

Technologies Used
- Java
- FreeTTS
- NetBeans IDE
- GitHub
